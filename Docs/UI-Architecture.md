# UI architecture

Reviewed: 2026-10-27 against main `d59d76f`. [Documentation index](README.md)

## Source and deployment

The application is HTML, CSS and JavaScript without a compiled frontend framework. Root [index.html](../index.html) owns the dashboard markup, styling and inline renderer. During the full refresh it is copied to public/index.html, then inject_session_analysis_ui.py adds the checkpoint/research renderer. Edit the source rather than only the generated public file.

Cloudflare serves ./public. JSON is generated by Python and committed before deployment. The browser renders snapshots; it does not collect scoring inputs or independently run the model.

## Page organization

[section-router.js](../public/section-router.js) maps query-string views:

| Route | Page |
|---|---|
| / | Overview |
| /?view=assessment | Assessment |
| /?view=analysis | Analysis |
| /?view=watch | Open Watch |
| legacy macro/internals views | Redirected logically to Overview |

These are filtered views of one document, not independent HTML applications. data-nd-page CSS controls visibility. A MutationObserver labels dynamically inserted groups. Group recognition is tied to heading text; changes to category names must be checked against the router.

## Modules and feed contracts

| Renderer | Input | Responsibility |
|---|---|---|
| Inline dashboard renderer | data/dashboard.json | Scores, factor cards, interpretation, detail panels and freshness |
| Inline chart renderer | data/chart-history.json | Stored chart observations; no fabricated future-date candles |
| Open Watch renderer | history/market-watch-events.json | Historical/active event presentation and confirmation |
| Analysis UI | data/session-research.json, session-analyses.json, premarket.json | Authored narratives and numeric checkpoint context |
| What to Watch | Current-date research catalysts/narrative, pre-market fallback | Researched event selection |
| Independent market tiles | data/live-indices.json | Cash/futures labels, timestamped values, percent change |
| Oil update | data/live-oil.json | Lightweight quote display update |
| Earnings AVWAP context | data/sox_avwap_latest.json | Coverage-aware research context |
| nvda-wavetrend.js | data/nvda-wavetrend.json; soxl-wavetrend.json | Reusable symbol WT card/chart with completed candles and source metadata |

The full dashboard loader fetches dashboard, event history and AVWAP concurrently, compares their timestamp signature and rerenders changed state. Optional-feed failure should not prevent the main quantitative page from rendering.

## Refresh and caching

| UI action | Configured behavior |
|---|---|
| Main snapshot poll | 2 minutes weekdays09:30–16:20 ET; 15 minutes pre/after-market04:00–09:30 and16:20–20:00; 1 hour otherwise |
| Macro-release attention window | Every20 seconds near a known release for10 minutes |
| Oil/index file poll | Every30 seconds |
| WT module | Every5 minutes while visible; also loaded with dashboard |
| Session tab selection | Time-aware repaint every minute when no manual tab |
| Check Latest button | Rereads snapshots and research; does not dispatch a collector |
| Tab visibility return | Rereads dashboard, oil, indices and analysis |
| Static cache headers | HTML and /data/* no-store/no-cache; HTML Refresh300 header |

Fetches use no-store and cache-busting query parameters. Browser polling cannot guarantee fresh upstream data or force a Cloudflare deployment.

Index collector marks source observations stale beyond20 minutes (or invalid future timestamps). UI also checks collection-age15 minutes and quote-age20 minutes. Yahoo quotes remain labelled delayed. Nasdaq Composite cash and Nasdaq100 futures are different instruments and must retain explicit names.

## Design and content rules

Maintain the selected minimalist black design, consistent typography, restrained signal colors, colored card borders and concise tooltips. Headings must outrank metadata/subheadings. Keep details readable without oversized mostly empty boxes. Mobile navigation should scroll rather than crowd.

Signal means directional contribution; trend means change; currentImpact means relevance now. A tooltip describes the metric; Details explains the current observation. Use “model” in product wording and keep implementation recipes out of normal product flows.

Authored narrative sessions, retrospective repairs and deterministic numeric checkpoints need distinct labels. Prefer explicit missing/unavailable states to invented continuity. Date labels and WT axes must correspond to actual stored candles.

## Safe UI verification

After a UI edit, check embedded JavaScript syntax, the router's heading detection, Overview/Assessment/Analysis/Watch, desktop/mobile overflow, unavailable feed states, dates/timestamps and source labels. WT browser tests cover module/widget contracts. This documentation-only change does not assert a fresh visual QA pass or live deployment verification.
